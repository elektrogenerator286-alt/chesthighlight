# Chest Highlight (Fabric 1.21.11)

Клиентский мод: подсвечивает сундуки сквозь стены.

| Цвет | Блок |
|---|---|
| жёлто-оранжевый | сундук |
| красный | сундук-ловушка |
| фиолетовый | эндер-сундук |
| зелёный | бочка |
| розовый | шалкер-бокс |

Клавиша **P** — включить/выключить (меняется в настройках управления).

## Сборка

Нужны JDK 21 и интернет.

```
gradle wrapper --gradle-version 9.2.1   # один раз, если нет gradlew
./gradlew build
```

Готовый jar: `build/libs/chesthighlight-1.0.0.jar` (не `-sources`).
Положите его в `mods/` вместе с Fabric Loader 0.18.1+ и Fabric API для 1.21.11.

Для запуска из IDE: `./gradlew runClient`.

## Как работает

- Раз в 10 тиков сканирует загруженные клиентом чанки и берёт блок-сущности нужных типов
  (данные уже есть на клиенте, лишних пакетов серверу не шлётся).
- Рисует полупрозрачные боксы через собственный `RenderPipeline` с отключённым depth-тестом.

## Замечание

На многих серверах (в том числе публичных) такие подсветки считаются читом и могут
привести к бану. Используйте в одиночной игре или там, где это разрешено правилами.
